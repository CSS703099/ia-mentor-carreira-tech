# IA Mentor de Carreira — Descubra seu Futuro em Tech

Projeto da DIO na trilha CI&T — Do Prompt ao Agente. Usa engenharia de prompt para
entrevistar uma pessoa iniciante ou em transição, comparar caminhos em tecnologia e
gerar um plano de estudo com uma entrega de portfólio.

## Como usar

1. Copie o [prompt de sistema](prompt.md) para uma conversa nova no Copilot ou no ChatGPT.
2. Inicie com “Quero descobrir qual área de tecnologia explorar”.
3. Responda à entrevista e confirme o resumo. Use dados fictícios para demonstração.
4. Revise a tabela de opções, o plano de quatro semanas e a atividade inicial.

## Decisões de projeto

O prompt usa entrevista em etapas, resumo confirmado e um formato de saída verificável.
A comparação considera interesse demonstrado, repertório e viabilidade. Em caso de
incerteza, propõe uma experiência curta com um critério de decisão. O mentor aproveita
respostas antecipadas e se limita a informações relevantes para o estudo.

Os [ensaios](evidencias.md) cobrem dois perfis contrastantes e incluem critérios de
conferência. O ensaio com evidências de interesse gera um plano de quatro semanas.
O caso com pouco repertório gera um experimento de sete dias. Os ensaios foram
produzidos em ChatGPT/Codex e o prompt pode ser usado em outros assistentes.
